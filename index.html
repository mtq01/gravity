About Orbit

Built on open standards, not guesswork.

Orbit doesn't invent its own accessibility rules. It's built on axe-core, the same engine used by major testing tools industry-wide, and pairs it with WCAG 2.x contrast math and The A11y Project's community-maintained checklist — so what you see in Orbit reflects established, peer-reviewed accessibility guidance.

  • Axe-core

    The open-source accessibility testing engine that powers Orbit's automated scans, built and maintained by Deque Systems and used across the industry.

    ↗

  • WCAG Guidelines

    The Web Content Accessibility Guidelines. The official W3C standard that defines what "accessible" means, and the benchmark Orbit's contrast checker and scanner test against.

    ↗

  • The A11y Project

    A community-driven effort making web accessibility easier to understand, with practical resources and the checklist that powers Orbit's manual audit tab.

    ↗

Methodology

Orbit automates what can be reliably automated, and is explicit about the rest. Automated tools like axe-core are excellent at catching objective, rule-based violations — but a meaningful share of WCAG success criteria require human judgment. Orbit is built around that line, not around pretending it doesn't exist.

What We Automate

  • Missing or empty alt attributes
  • Insufficient color contrast ratios
  • Missing form labels
  • Invalid or misused ARIA attributes
  • Missing document landmarks
  • Duplicate IDs
  • Missing page language attributes
  • Heading structure issues (ex. skipped levels)

What We Don't

  • Whether alt text is accurate and meaningful, not just present
  • Whether reading order makes logical sense to a screen reader user
  • Whether a custom widget is actually operable with a keyboard, not just tagged correctly
  • Whether error messages are genuinely clear and actionable
  • Whether content makes sense when read out of visual context
  • Whether an interaction pattern is intuitive for someone using a screen reader or switch device day-to-day

No automated scanner, including Orbit, can verify these. They require a human tester, ideally one using the assitive technology in question.
